# Дашборды Mafia&Casta

Опубликованные управленческие дашборды сети. Каждая страница зашифрована
паролем: в файле лежит только шифротекст, расшифровка происходит в браузере.

| Дашборд | Адрес | Источник |
|---|---|---|
| Retention | [/retention/](https://alexprikhodk-code.github.io/Mafia-Dashboards/retention/) | Syrve, пересобирается ежедневно в 12:00 |

## Как это устроено

Содержимое борда шифруется AES-256-GCM, ключ выводится из пароля через
PBKDF2-HMAC-SHA256 с 600 000 итераций. Хостинг пароля не знает и знать не может:
он раздаёт статический файл, а расшифровка идёт через Web Crypto на стороне
зрителя. Поэтому защита работает и на GitHub Pages, где своей авторизации нет.

Важно понимать границы: пароль один на всех, отозвать доступ конкретному
человеку нельзя — только сменить пароль и перевыложить страницу. Шифротекст
может скачать любой, у кого есть ссылка, и подбирать пароль офлайн, поэтому
стойкость целиком зависит от длины и случайности пароля.

## Как обновляется

Репозиторий заполняется автоматически из проекта `AI Syrve Connect`:
`scripts/update_retention_daily.py` выгружает данные из Syrve, пересобирает
борд, шифрует его и делает push. GitHub Pages подхватывает изменения сам.

Руками, вне расписания:

```bash
python scripts/update_retention_daily.py --publish
```

Сменить пароль — вписать новый в `.board_password` в корне проекта и
пересобрать: страница перешифруется, старый пароль перестанет подходить.

Исходники, данные и пароль в этот репозиторий не попадают.
